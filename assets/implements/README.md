# Attachment posters

`assembled/` contains the five optimized WebP rover configurations used by the desktop poster carousel and the static first poster. Runtime URLs remain `/implements/assembled/arms.webp`, `spraying.webp`, `hitch.webp`, `trolley.webp` and `trey.webp`.

The original full-resolution renders and unused isolated implement PNGs have been removed. Keep these assembled posters: they support reduced motion, no WebGL, no JavaScript and small screens.
